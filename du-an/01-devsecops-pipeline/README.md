## Phạm vi / yêu cầu

- [ ] Chọn 1 đồ án Java/Spring làm đối tượng
- [ ] Pipeline: build → SAST (Semgrep/CodeQL) → SCA (Dependency-Check/Trivy) → secret scan (Gitleaks) → DAST (ZAP) → IaC scan (Checkov)
- [ ] Security gate chặn build khi có lỗi mức High+
- [ ] SBOM (CycloneDX) + ký artifact (cosign)
- [ ] Báo cáo trước/sau: số lỗ hổng, thời gian pipeline
