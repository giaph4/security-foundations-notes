## Quy ước

- **1 chương = 1 file** `.md` (copy từ cấu trúc có sẵn, đã được sinh sẵn cho bạn).
- Ảnh để trong thư mục `anh/` cạnh file, đặt tên `<mã-chương>-<mô-tả>.png`.
- Trạng thái dùng emoji: ⬜ chưa · 🟨 đang · ✅ xong · ⏸ tạm dừng · ❌ bỏ.
- Ghi chú **bằng lời của mình**, không chép nguyên văn; link nguồn gốc khi trích.
- **Không** lưu mật khẩu, API key, token, dữ liệu thật, flag của giải CTF đang diễn ra vào kho này (nếu đẩy lên GitHub sẽ lộ).
- Commit thường xuyên: `git init` + 1 commit mỗi buổi học (xem [cong-cu-va-cai-dat.md](00-bat-dau/cong-cu-va-cai-dat.md)).
