# Từ điển thuật ngữ cá nhân

> Mỗi khi gặp thuật ngữ lạ → thêm 1 dòng (giữ thứ tự A–Z). Cột "Chương" link về nơi gặp lần đầu.

| Thuật ngữ | Viết đầy đủ | Nghĩa (bằng lời mình) | Ví dụ | Chương |
| --- | --- | --- | --- | --- |
| AAA | Authentication, Authorization, Accounting | Xác thực – phân quyền – truy vết | Đăng nhập → quyền đọc file → log truy cập |  |
| ALE | Annualized Loss Expectancy | Tổn thất kỳ vọng/năm = SLE × ARO | 50 triệu × 0.2 = 10 triệu |  |
| APT | Advanced Persistent Threat | Nhóm tấn công có tổ chức, dai dẳng |  |  |
| ATT&CK | MITRE ATT&CK | Kho tri thức tactic/technique kẻ tấn công |  |  |
| C2 | Command & Control | Kênh điều khiển máy bị chiếm |  |  |
| CIA | Confidentiality, Integrity, Availability | 3 thuộc tính bảo mật cốt lõi |  |  |
| CVE | Common Vulnerabilities and Exposures | Mã định danh lỗ hổng công khai | CVE-2021-44228 |  |
| CVSS | Common Vulnerability Scoring System | Điểm mức độ nghiêm trọng 0–10 |  |  |
| EDR | Endpoint Detection & Response | Giám sát & phản ứng trên máy trạm |  |  |
| EPSS | Exploit Prediction Scoring System | Xác suất bị khai thác thực tế |  |  |
| IOC | Indicator of Compromise | Dấu hiệu bị xâm nhập (hash, IP, domain) |  |  |
| KEV | Known Exploited Vulnerabilities | Danh mục CISA các lỗ hổng đang bị khai thác |  |  |
| MFA | Multi-Factor Authentication | Xác thực nhiều yếu tố |  |  |
| MTTD / MTTR | Mean Time To Detect / Respond | Thời gian trung bình phát hiện / xử lý |  |  |
| PAM | Privileged Access Management | Quản lý tài khoản đặc quyền |  |  |
| SIEM | Security Information & Event Management | Gom log, tương quan, cảnh báo |  |  |
| SOAR | Security Orchestration, Automation & Response | Tự động hoá phản ứng |  |  |
| STRIDE | Spoofing, Tampering, Repudiation, Info disclosure, DoS, EoP | Khung mô hình hoá mối đe dọa |  |  |
| TTP | Tactics, Techniques, Procedures | Hành vi của kẻ tấn công |  |  |
| XSS | Cross-Site Scripting | Chèn script vào trang của người khác |  |  |
