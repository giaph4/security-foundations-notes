# Flashcards

## Nguyên tắc

- Viết flashcards **ngay trong file chương** (mục 10) theo cú pháp `Hỏi :: Đáp`.
- 1 thẻ = 1 ý. Câu hỏi hướng vào **"tại sao / khi nào / khác gì"** hơn là định nghĩa suông.
- Thẻ tốt: *"Vì sao ECB mode không an toàn cho ảnh?"* — thẻ dở: *"ECB là gì?"*.

## Dùng với Obsidian

Plugin **Spaced Repetition** → Settings → "Flashcard tags": thêm `#flashcards`. Đặt dòng `#flashcards` đầu mục 10 của chương nào muốn ôn.

## Dùng với Anki

Gom thẻ sang file CSV (`Hỏi;Đáp`) trong thư mục này rồi *File → Import* trong Anki.
